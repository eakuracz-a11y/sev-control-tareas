# SEV Control de Tareas V2.0

Versión reconstruida desde cero.

## Incluye
- Identidad visual Sevion minimalista.
- Sectores LAB / PRD / LOG / MANT.
- Áreas FUN / BIO / FER / ADJ.
- Mantenimiento: Preventivo / Correctivo / Proactivo / Predictivo.
- Semáforo de cumplimiento.
- Avance real vs. teórico.
- Fechas de inicio y finalización.
- Gantt dinámico.
- Filtros por sector, área, operario y estado.
- Calendario.
- Tareas recurrentes.
- Portal por enlace/token para responsables.
- Actualización diaria.
- Cierre exclusivo por administrador.
- Precarga inicial de las 28 tareas históricas de Camille en LAB-FER.

## Ejecutar
```bash
pip install -r requirements.txt
streamlit run app.py
```
